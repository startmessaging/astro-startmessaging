### The 5 Hidden Costs in Indian OTP Pricing

When evaluating cheap OTP services in India, engineering teams must account for five distinct hidden cost factors:

1. **DLT Onboarding & Maintenance Fees:** Under [TRAI's TCCCPR rules](https://trai.gov.in), traditional SMS providers require you to register as a Principal Entity (PE) on telecom DLT portals (such as Jio Trueconnect, Airtel DLT, or Vi). DLT registration costs ₹5,900 as a one-time fee, plus annual re-KYC fees per operator. If you use self-service DLT gateways, this overhead must be amortized over your OTP volume.
2. **Template Approval Friction & Engineering Hours:** Every unique SMS message format requires manual DLT template approval. Teams spend an average of 10 to 20 engineering hours submitting forms, handling template rejections, and binding headers. Factoring developer salaries into onboarding, DIY DLT adds ₹15,000 to ₹30,000 in indirect setup costs.
3. **Monthly Minimum Commitments & Wallet Expiration:** Many legacy gateways enforce a minimum monthly spend (e.g., ₹1,000/month) or cause unused prepaid wallet balances to expire after 30 to 90 days. If your startup sends only 5,000 OTPs in a slow month, your effective unit price spikes dramatically.
4. **International OTP Markups:** If an international customer attempts to log into your app using a non-+91 phone number (e.g., UAE +971 or US +1), legacy Indian providers route the message via international SMS routes, charging ₹2.50 to ₹7.50 per OTP without warning.
5. **Voice OTP Fallback Surcharges:** When SMS delivery fails due to carrier network congestion, triggering a voice call OTP fallback costs ₹0.45 to ₹0.90 per call.

A provider’s value is not measured solely in rupees—it is also measured in developer setup time and API ergonomics.

```typescript
import 'dotenv/config';

const API_KEY = process.env.STARTMESSAGING_API_KEY!;
const BASE_URL = 'https://api.startmessaging.com';

// 1. Dispatch OTP (Generates code & delivers via SMS)
async function sendOtp(phoneNumber: string) {
  const response = await fetch(`${BASE_URL}/otp/send`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'X-API-Key': API_KEY,
    },
    body: JSON.stringify({ phoneNumber }),
  });

  const payload = await response.json();
  if (!response.ok) {
    throw new Error(payload.message || 'Failed to dispatch OTP');
  }

  // Returns: { requestId: 'req_12345', expiresAt: '2026-08-26T12:10:00Z', attemptsLeft: 3 }
  return payload.data;
}

// 2. Verify OTP
async function verifyOtp(requestId: string, code: string) {
  const response = await fetch(`${BASE_URL}/otp/verify`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'X-API-Key': API_KEY,
    },
    body: JSON.stringify({ requestId, otpCode: code }),
  });

  const payload = await response.json();
  return payload.data?.verified === true;
```

## Evaluating OTP Deliverability and SLA Beyond Cost

A provider offering ₹0.12 per OTP is unprofitable if 10% of your verification codes fail to arrive. When an OTP fails to deliver within 30 seconds, users abandon the onboarding flow.

### Key Deliverability Metrics to Test Before Committing

1. **P95 Latency SLA:** Measure the 95th percentile delivery speed across all four major Indian carriers (Jio, Airtel, Vi, BSNL). High-quality direct routes deliver 95% of messages in under 4 seconds.
2. **Multi-Operator Fallback:** Check whether the provider uses intelligent multi-operator routing. If Airtel's SMSC experiences local network congestion, the gateway should instantly fail over to Jio or Vi routing pipelines.
3. **Delivery Webhook Accuracy:** Ensure the API returns real-time delivery receipts (DLRs) so your application can trigger voice or email fallback routes when network drops occur.
